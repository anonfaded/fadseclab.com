# FadSec Lab // Interactive Hub

The official landing hub for **FadSec Lab**, a specialized studio dedicated to building **Free and Open Source (FOSS)** applications for Android and Desktop platforms.

## 👁️ The Vision

FadSec Lab bridges the gap between high-level security research and accessible user interaction. We focus on creating tools that are:
- **Transparent**: Fully open-source and community-audited.
- **Secure**: Built with production-grade cryptography and privacy-first architectures.
- **Interactive**: Featuring premium, highly-responsive user interfaces (like our signature interactive avatar).

## 🚀 Key Features

| Feature | Description |
|---------|-------------|
| 👁️ **Identity Hub** | Interactive avatar with dual-mode eye tracking (Mouse Red / Keyboard White) |
| ☸️ **Arc Navigation** | Modern curved navigation system positioned above the avatar head |
| 🛡️ **Awareness UI** | Explicit confirmation dialogs for secure external uplinks |
| 📱 **Cross-Platform** | Optimized for Android-centric toolsets and Desktop security utilities |
| ⚡ **Tech Stack** | React 18, TypeScript, Vite, Framer Motion, GSAP, and Lucide Icons |

## 🛠️ Development Setup

This project is managed with `pnpm`.

```bash
# 1. Install dependencies
pnpm install

# 2. Start development server
pnpm dev

# 3. Build for production
pnpm build
```
