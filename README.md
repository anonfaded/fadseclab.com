# fadseclab.com

Landing page for [FadSec Lab](https://fadseclab.com) — anti-adversary, open-source software for Android, iOS, and desktop.

## Dev

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # production build → dist/
```

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · GSAP · Three.js · Framer Motion
