// PRIORITY ISSUES
P0

Default type with no voice

Manrope + JetBrains Mono are both 2024–2026 defaults. Manrope is the new Inter — every Vercel-deployed landing ships it. For a privacy-first FOSS company, the type needs a voice that signals "we engineer for a living." Visible at index.css import + @theme inline block.

FIX: /design typeset — pick a type pair that earns its place. Consider a sharper workhorse (Söhne, Switzer, GT America) or a serif-led brand (Fraunces / PP Editorial New on the hero) paired with a single mono for axis labels.
P0

Feature tile grid in services

.service-grid renders three identical cards: Lucide icon, h3, paragraph. None prioritized. The three cards are interchangeable. This is the canonical agency-services layout.

FIX: /design relayout — demote the grid. Make Native Android the lead service in detail; collapse the other two into a single column row or a process-step list.
P1

Stat monument before proof

First thing after hero is "150K+ users trust us" 4xl. The interesting parts (zero trackers, public source, CNN press) sit below the stat band. The 150K+ number is the least-interesting part of the privacy-first FOSS story.

FIX: /design relayout — lead proof, not stats. Add a press-credible artifact (As featured in, GitHub stars, single quote attribution) above the metrics; demote the 150K+ to a footer line.
P1

Unearned blur on floating header

.site-header uses backdrop-filter: blur(22px) on a 90%-transparent pill. The page has not established a 3-plane depth system (background / content / attention). The blur is decoration, not architecture. Mobile menu repeats the trick at 24px.

FIX: /design interaction — commit to a depth system or drop the blur. Either a real overlay plane across the site, or a solid header pill that matches the rest of the surface language.
P2

Center stack across the page

Hero is centered (correct — Decide surface). But proof band, product section, services section, and footer wordmark all default to centered layouts. The page looks the same section-to-section.

FIX: /design relayout — keep hero centered, give every other section a composition that matches its work-pattern. Proof wants compare (asymmetric). Products wants operate (flagship card + catalog strip). Services wants decide (single lead paragraph + one-line roster).
P2

Footer wordmark hover-reveal

.footer-wordmark uses CSS-only translateY hover swap: gray "FadSec" slides up, red "Lab" slides in. A 2018-era brand-site trick, now standard issue on Vercel/Linear-style landings.

FIX: /design voice or /design refine — replace the hover reveal with a single, intentional footer wordmark: pressed-stamp, mono transcript of repo count, flagged shield silhouette at footer scale.
